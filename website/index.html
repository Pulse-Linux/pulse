Setup & Deployment

Installation & Hardware Guide

Deploy Pulse Linux on bare-metal hardware or test it immediately in your favorite virtual machine.

Creating a Bootable Pulse Linux USB Drive

Write the downloaded ISO image to any USB drive (minimum 2 GB). You can use graphical utilities or the command line:

BalenaEtcher

Cross-platform (Linux, Windows, macOS). Select the ISO, pick your USB stick, and click Flash.

Rufus (Windows)

Select target USB and write in DD Image mode for exact byte matching.

Command Line (dd)

sudo dd if=pulse.iso of=/dev/sdX bs=4M status=progress

⚠️ Always verify the target disk name (`lsblk`) before running `dd` to avoid overwriting existing data.

Running in QEMU / KVM Virtual Machine

Test Pulse Linux inside Linux with near-native virtualization speed using QEMU:

# 1. Create a 15GB virtual disk:
qemu-img create -f qcow2 pulse-disk.qcow2 15G
# 2. Boot Pulse Linux Workstation ISO with 4GB RAM & 2 CPU cores:
qemu-system-x86_64 -m 4096 -smp 2 -enable-kvm -cdrom pulse-linux-1.0-gnome-amd64.iso -hda pulse-disk.qcow2 -boot d

For VirtualBox or VMware: select Type Linux, Version Debian (64-bit), allocate 4096 MB RAM, and attach the ISO to the virtual optical drive.
