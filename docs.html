CHAPTER 01

Getting Started with Pulse Linux

Pulse Linux is distributed as a hybrid Live/Install ISO. When booted from a USB drive or virtual machine, it boots into a fully functional live environment without altering your local hard disks.

Workstation Edition: Automatically starts the GNOME 43 graphical desktop environment with complete display auto-detection.

Core Edition: Boots into a high-speed CLI shell with full networking tools (`nmtui`, `ip`, `ssh`).

CHAPTER 03

Installing to Disk: pulse-install

Pulse Linux features a custom-engineered guided installer located at `/usr/local/bin/pulse-install`. You can launch it from the GNOME application launcher or directly via terminal.

# Launch the graphical or interactive installer:
sudo pulse-install
# Automated unattended install to a specific disk:
sudo pulse-install --target /dev/sda --edition workstation --encrypt

• Automatic Partitioning: Creates EFI System Partition (ESP), Ext4 root partition, and ZRAM swap.

• LUKS2 Encryption: Supports military-grade Argon2id encryption for complete disk security.

• UEFI & BIOS GRUB: Installs universal bootloader compatible with both legacy and modern hardware.

CHAPTER 04

Pulse Command Suite Reference

Pulse Linux ships with a unified administrative CLI tool called pulse:

pulse info System Specifications

Outputs a quick hardware, kernel, desktop environment, and repository overview.

$ pulse info
pulse doctor Health & Diagnostics

Runs system health verifications: validates APT mirrors, checks DKMS modules, monitors disk SMART health, and inspects AppArmor security status.

$ pulse doctor
pulse theme [set|list] Desktop Appearance

Lists available visual themes and switches the GNOME shell theme, GTK4 accent colors, icon pack, and desktop wallpaper in a single command.

$ pulse theme set pulse-cyber-neon
pulse module [enable|run|list] Security Sandbox

Manages isolated offensive security toolchains (Kali packages) inside dedicated AppArmor containers.

$ pulse module enable kali-core

CHAPTER 06

Kali Linux Security Sandboxing

In standard distributions, adding Kali repositories to a Debian or Ubuntu system causes severe dependency hell because Kali regularly tracks bleeding-edge rolling libraries.

Pulse Linux solves this by utilizing Modular Security Isolation:

1. Kali utilities run in decoupled containerized namespaces with shared X11/Wayland and network socket forwarding.

2. Debian Bookworm desktop libraries remain 100% pure and untouched.

3. All security scans, packet captures, and reverse engineering tools execute with full hardware speed while keeping your base workstation safe from breakage.
